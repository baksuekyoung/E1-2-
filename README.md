# 🎯 나만의 퀴즈 게임 (Python Console Quiz Game)

Python 기본 문법, 객체지향(OOP), 파일 입출력(JSON), 그리고 Git 형상 관리 협업 워크플로우를 활용하여 터미널(콘솔) 환경에서 동작하도록 구현한 인터랙티브 퀴즈 게임 프로그램입니다.

---

## 📌 1. 프로젝트 개요
* **개발 기간**: 2026년 11월
* **개발 언어**: Python (3.10 이상 권장)
* **주요 특징**:
  - `Quiz` 및 `QuizGame` 클래스를 활용한 객체지향 설계
  - `state.json`을 통한 데이터 영속성 보장 (프로그램 종료 후 재실행 시 퀴즈 및 최고 점수, 히스토리 유지)
  - `try/except` 기반의 강력한 입력 예외 처리 및 비정상 종료(Ctrl+C, EOF) 방지
  - 보너스 기능 포함: **랜덤 출제, 문제 수 선택, 힌트 기능, 퀴즈 삭제, 점수 히스토리 기록**

---

## 💡 2. 퀴즈 주제 및 선정 이유
* **주제**: 프로그래밍(Python), IT 상식 및 교양 퀴즈
* **선정 이유**: 학습 과정에서 익힌 파이썬 기초 문법과 객체지향 구조를 직접 코드로 구현해보기에 가장 직관적이며, 사용자가 직접 문제를 추가하고 학습할 수 있는 확장성이 높아 커뮤니티 교육 및 퀴즈 콘텐츠로 활용하기 적합하기 때문입니다.
